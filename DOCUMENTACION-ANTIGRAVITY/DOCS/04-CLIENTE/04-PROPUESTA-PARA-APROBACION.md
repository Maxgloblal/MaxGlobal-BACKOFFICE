```
   1. El cliente arma su pedido en la web

              │
              ▼

              │

              │

              │

              │

              │
              ▼
```

# PARTE 4b · SOBRE EL RANGO Y EL ACUMULADO

Usted mencionó que lleva la cuenta en Excel de cuánto hace cada líder mes a
mes, para pagar el Bono Global a los 6 meses.

## Buenas noticias: eso ya no va a ser necesario

El sistema guarda **todo el histórico** de puntos. El "reseteo" mensual solo
significa que el mes nuevo arranca en cero — **la información anterior nunca se
borra.**

Entonces el backoffice puede mostrarle esto, actualizado solo:

```
   REPORTE DE ACUMULADOS

   Socio             Este mes    Acumulado    Rango máx
   ────────────────────────────────────────────────────
   Carlos Mendoza       2,340       24,890    Diamante
   María Torres         2,100       18,450    Oro
   Julio Manrique         890        7,120    Plata
   ────────────────────────────────────────────────────
   TOTAL DE LA RED     45,780      312,440

   Bono Global (1%)  →  3,124 puntos a repartir
```

**Sin anotar nada a mano.**

## Y una consulta sobre el rango

Usted preguntó si, al acumularse los puntos, el socio debería cobrar Oro cuando
el acumulado llegue ahí. Hay dos formas y quiero confirmarlo:

| | **A · Rango mensual** | **B · Rango acumulado** |
|---|---|---|
| Cómo funciona | Califica con el volumen de ese mes | El puntaje se suma de por vida |
| Si un mes baja | Ese mes no cobra bono de rango | Nunca baja de rango |
| Costo para la empresa | Predecible mes a mes | 🔴 Crece y nunca baja |

> **Sobre la opción B, algo que conviene ver:** si el rango se acumula de por
> vida y el bono se paga cada mes, un socio que llegó a Diamante hace dos años
> seguiría cobrando **S/. 10,000 mensuales** aunque su red ya no venda nada.

### Mi propuesta

**Que cobre según el mes, pero que conserve su rango más alto como título
honorífico.**

```
   ┌──────────────────────────────────────┐
   │  Tu rango más alto:  ORO 🏅          │  ← nunca baja
   │  Rango de este mes:  PLATA           │  ← el que cobra
   │  Bono a cobrar:      S/. 200         │
   └──────────────────────────────────────┘
```

Así el socio no pierde el reconocimiento que ganó —lo ve en su panel, lo puede
mostrar— pero el costo para la empresa se mantiene sostenible.

**¿Le parece bien así, o prefiere que sea acumulado?**

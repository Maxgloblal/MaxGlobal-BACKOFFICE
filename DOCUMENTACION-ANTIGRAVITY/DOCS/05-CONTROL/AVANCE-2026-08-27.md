# 2 · 🔴 EL SEO NO ESTABA TERMINADO

**Jack preguntó por el dominio y las vistas previas al compartir.** Al revisar
apareció un fallo que yo había dado por resuelto.

## Qué pasa

**Compartir cualquier producto por WhatsApp muestra la tarjeta de la portada.**
Las 14 páginas, la misma tarjeta.

## Por qué

El sitio es una SPA: las 14 rutas devuelven el mismo `dist/index.html`, con las
etiquetas `og:` fijas de la portada.

```bash
grep -rn "og:image\|og:title\|og:url" src/
→ (vacío)     ningún archivo las toca
```

**Y aunque las tocara, no serviría: el robot de WhatsApp no ejecuta
JavaScript.** Pide el HTML, lee las etiquetas y se va antes de que React arranque.

## El efecto secundario

La canónica también la pone JavaScript. **El HTML crudo dice `canonical → /` en
las 14 páginas.** Google sí renderiza JS, así que la termina viendo, pero en una
segunda pasada que puede tardar semanas.

**El de WhatsApp es certero. El de Google es un riesgo.** No son lo mismo.

## El dominio

`maxglobaloficial.com` está escrito a mano en **26 lugares** — sitemap 14,
index.html 7, App.jsx 3, robots 1, config 1. **Y nadie ha confirmado que esté
disponible.**

## Mi error

**Revisé que las etiquetas existieran, sin preguntarme si el robot llegaba a
verlas.** Mismo tipo de fallo que el de móvil: verificar que el código está no es
verificar que funciona.

**Regla nueva, ya en el mapa de mantenimiento:** para SEO se audita el HTML
**servido**, no el código.

```bash
curl -s https://DOMINIO/productos/cafe-moringa | grep 'og:title'
```

## La solución

**Prerenderizado al compilar** — un HTML real por ruta. No se reescribe el sitio
ni se migra a Next.js: es un script posterior a `npm run build`. **Es la
TAREA-08.**

**Documento:** `SITIO WEB.../SEO-Y-DOMINIO.md`

## Pero salió fuera de orden

## Y con un problema real

```js
montoEsperado: '150.00',      🔴  texto con decimales
totalAPagar: '42,380.00',     🔴  y con coma de miles
```

**El dinero debe ser entero en céntimos** — Artículo II. Y el formateo quedó
escrito a mano en 4 páginas, `S/. ${valor}`, unas 15 veces.

Hoy no rompe porque nada calcula. **Pero cuando lleguen los céntimos reales:**

```
   S/. ${15000}          →  "S/. 15000"      muestra quince mil
   '150.00' + '80.40'    →  "150.0080.40"    concatena en vez de sumar
   parseFloat('1,200.00') →  1               la coma lo corta
```

**Es exactamente el riesgo de construir pantallas antes que la base**, y se
confirmó el mismo día en que se argumentó.

**Corrección:** `TAREA-02B` — 4 archivos de datos y una función. Después serían
20 pantallas.

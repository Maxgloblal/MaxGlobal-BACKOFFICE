## Para qué sirve el mapa de mantenimiento

Cada error que costó tiempo queda anotado con su lección. Van más de diez:
archivos corrompidos, reportes que declaraban más de lo verificado, resúmenes
que perdieron un matiz y provocaron decisiones equivocadas.

**Se lee antes de empezar una tarea nueva, no después del accidente.**
